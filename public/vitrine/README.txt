Photos produits de la page d'accueil vitrine (/).

Déposer ici les fichiers suivants (JPG, format paysage ~1600x1000, < ~300 Ko chacun) :

  volet-roulant.jpg      -> carte « Volets roulants »
  volets-battants.jpg    -> carte « Volets battants & coulissants »
  porte-garage.jpg       -> carte « Porte de garage enroulable »
  moustiquaire.jpg       -> carte « Moustiquaires »
  portails-clotures.jpg  -> carte « Portails & clôtures »
  bloc-baie.jpg          -> carte « Bloc baie »
  vue_generale.jpg       -> visuel du hero (bandeau d'accueil)

Tant qu'un fichier est absent, la carte (ou le hero) affiche un dégradé marine
de repli — aucune image cassée. Les chemins sont référencés dans
components/vitrine/VitrineHome.tsx (champ `img` + visuel hero).
